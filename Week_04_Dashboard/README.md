# Week 4 — Interactive Sales Dashboard

A self-contained HTML dashboard with Year, Region and Category filters, KPI cards and charts. An Excel KPI workbook supplements the browser dashboard.

**KPIs:** sales, profit, profit margin and transaction lines. The HTML dashboard can be opened in a modern browser without internet.
