# NexAfrica — Five-Week Data Analysis Internship Portfolio

A Superstore retail sales analytics portfolio organised into five weekly projects. Historical sample data (2014–2017), not live company results.

| Week | Focus | Folder |
|---|---|---|
| 1 | Data cleaning and preparation | `Week_01_Cleaning/` |
| 2 | Python exploratory data analysis | `Week_02_EDA/` |
| 3 | SQL business analysis | `Week_03_SQL/` |
| 4 | Interactive dashboard | `Week_04_Dashboard/` |
| 5 | Capstone reporting | `Week_05_Capstone/` |

**Summary:** 9,994 order lines; $2,297,200.86 sales; $286,397.02 profit; 12.47% profit margin. Technology leads category sales and West leads regional sales.

**Project files:** Full original submissions include CSV, Excel, Jupyter notebooks, SQL database, HTML dashboard, charts and presentation. The documentation is published here first; large/binary project artifacts have not yet been uploaded.
