# Week 2 — Exploratory Data Analysis

Python analysis of cleaned Superstore data: sales, profit, regions, categories, discounting and time trends.

**Key results:** 9,994 order lines; $2,297,200.86 sales; $286,397.02 profit (12.47% margin). Technology leads category revenue ($836,154), West leads regional sales ($725,458), and Tables lost about $17,725. Discounting is associated with losses, but correlation does not prove causation.
